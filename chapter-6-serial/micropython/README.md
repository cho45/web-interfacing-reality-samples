# MicroPython Web Serial

[日本語](#japanese) | [English](#english)

---

<a id="english"></a>
## English

A sample for controlling MicroPython REPL on Raspberry Pi Pico from the browser using the Web Serial API.

### Setup

1. Install MicroPython firmware on your Raspberry Pi Pico.
2. Connect Pico to your PC via USB.

### How to Use

1. Open `index.html` in a browser (Web Serial API requires Chrome or compatible browser).
2. Click the **"Connect"** button and select the serial port.
3. You can send commands, run LED blink demo, and read the temperature sensor.

<a id="japanese"></a>
## 日本語

Web Serial API を使用して、ブラウザから Raspberry Pi Pico 上の MicroPython REPL を操作するサンプルです。

### セットアップ

1. Raspberry Pi Pico に MicroPython ファームウェアをインストールします。
2. Pico を PC に USB 接続します。

### 使い方

1. `index.html` をブラウザで開きます（Web Serial API は Chrome 等の対応ブラウザが必要です）。
2. **「接続」**ボタンをクリックし、シリアルポートを選択します。
3. コマンドの送信や、Lチカ、温度センサーの読み取りなどのデモを実行できます。
