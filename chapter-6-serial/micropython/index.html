Verification Items

  • Can receive REPL prompt (>>>)
  • Can receive response after sending command
  • Can distinguish REPL output from data
  • Error messages display correctly
  • Control characters (Ctrl+C, Ctrl+D) work
  • Clean output in Raw REPL mode

MicroPython REPL Control Characters

  • \x03 (Ctrl+C): Interrupt running program
  • \x01 (Ctrl+A): Enter Raw REPL mode
  • \x02 (Ctrl+B): Return to normal REPL mode
  • \x04 (Ctrl+D): Soft reboot / Exit paste mode
  • \x05 (Ctrl+E): Enter paste mode

How to Use

  1. Write MicroPython uf2 to Raspberry Pi Pico
  2. Click 'Connect' button to select serial port
  3. Confirm REPL prompt appears
  4. Send commands to verify operation
