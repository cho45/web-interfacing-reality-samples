# Haptic Feedback (Vibration API)

[日本語](#japanese) | [English](#english)

---

<a id="english"></a>
## English

A sample that controls smartphone vibration using the Vibration API.

### How to Use

1. Open `index.html` in a browser that supports the Vibration API (e.g., Chrome for Android).
2. Tap each button to feel the specified vibration pattern.

---

<a id="japanese"></a>
## 日本語

Vibration API を使用して、スマートフォンのバイブレーションを制御するサンプルです。

### 使い方

1. Vibration API に対応したブラウザ（Android 版 Chrome など）で `index.html` を開きます。
2. 各ボタンをタップすると、指定されたパターンでスマートフォンが振動します。
