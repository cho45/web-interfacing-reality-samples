7 Ways to Interact with the Real World from JavaScript

Sample Applications
  • Chapter 1 Light - QR Code Generator Display input text as a QR code, data transmission via spatial light patterns.
  • Chapter 1 Light - Screen Light Communication (Morse Code via OOK) Light communication prototype using screen flashing as a light source, decoded by camera.
  • Chapter 2 Vibration - Haptic Feedback (Vibration API) Demo controlling physical vibration patterns using the Vibration API.
  • Chapter 2 Vibration - Game Controller (Gamepad API) Demo for reading controller state and controlling vibration using the Gamepad API.
  • Chapter 3 Sound - Basic Waveforms and Visualization (Web Audio API) Sound generation with oscillators and real-time visualization using AnalyserNode.
  • Chapter 3 Sound - Synthesizer (Polyphonic Synth) Implementation of a polyphonic synthesizer playable with a PC keyboard.
  • Chapter 3 Sound - Acoustic Communication (300bps FSK Modem) Data transmission/reception modem via sound using Web Audio API and AudioWorklet.
  • Chapter 4 HID - Report Debugger Visualize raw binary data sent from devices using the WebHID API.
  • Chapter 6 Serial - MicroPython Web Serial Directly control a microcontroller (Raspberry Pi Pico) from the browser via Web Serial API.
